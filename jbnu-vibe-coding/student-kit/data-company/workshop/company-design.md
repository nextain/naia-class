# 모두봄랩 — 회사 디자인 정보

> 교육용 가상 브랜드 가이드입니다.

## 브랜드 인상

따뜻함, 쉬움, 실용성, 신뢰, 지역 공동체를 핵심 인상으로 합니다. 기술을 과시하기보다 소상공인이 부담 없이 시작하도록 돕는 분위기를 냅니다.

## 색상

| 이름 | 값 | 용도 |
|---|---|---|
| 봄빛 초록 | `#7BCB3B` | 핵심 버튼, 강조 |
| 따뜻한 산호 | `#FF7658` | 보조 강조, 작은 포인트 |
| 짙은 먹색 | `#343A46` | 제목과 본문 |
| 크림 | `#FFF9EF` | 넓은 배경 |
| 흰색 | `#FFFFFF` | 카드 배경 |

## 글꼴과 화면

- 기본 글꼴: `Pretendard`, 없으면 시스템 sans-serif
- 제목은 짧고 굵게, 본문은 한 문단 3~4줄 이내
- 큰 둥근 모서리와 넉넉한 여백을 사용
- 원페이지 순서: 소개 → 고객 문제 → 해결 방법 → 핵심 기능 → 활동 → 문의
- 모바일에서 먼저 읽히도록 구성하고 텍스트 대비를 충분히 확보

## 로고 사용

- `modubom-logo.png` 원본 비율을 유지합니다.
- 흰색 또는 크림색 배경에서 사용합니다.
- 늘이기, 색상 변경, 과한 그림자, 일부 잘라내기를 하지 않습니다.
- 로고 주변에는 로고 높이의 약 1/4 이상 여백을 둡니다.

## 사진 방향

- 자연광, 실제 활동을 관찰한 듯한 장면
- 지역 상점과 교육 현장의 따뜻하고 담백한 분위기
- 악수 포즈나 과장된 성공 연출은 피함
- 실존 인물, 실제 고객, 실제 상표를 추정하지 않음
- 모든 사진은 교육용 가상 이미지임을 페이지 하단에 표시

## 피해야 할 것

- SVG 로고나 새 로고를 임의로 만들기
- 자료에 없는 고객 수, 매출, 수상 경력 표시
- 지나치게 화려한 애니메이션
- 읽기 어려운 연한 본문 색상
- 실제 연락처처럼 보이는 임의 정보
