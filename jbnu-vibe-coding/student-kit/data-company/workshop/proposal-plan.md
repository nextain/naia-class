# 모두봄랩 — 제안서 작성용 계획 정보

> 교육용 가상 계획입니다. 실제 사업계획이나 확정 목표가 아닙니다. `achievements.md`의 과거 가상 활동과 섞지 않습니다.

## 협약기간 산출물 가정

- 소상공인용 웹 기반 서비스 최소기능제품(MVP) 1개
- 업종별 원페이지 템플릿 3개: 꽃집, 카페, 소규모 공방
- 사용자가 직접 문구와 사진을 바꿀 수 있는 편집 안내서 1개

위 수량은 수업용 제안서 작성을 위해 명시적으로 설정한 미래 목표입니다. `achievements.md`의 시제품 3종과 숫자가 같아도 서로 다른 항목입니다.

## 개발 범위 가정

1. 구조화된 질문으로 가게 소개 정보를 받습니다.
2. 입력 내용을 원페이지 섹션에 맞게 정리합니다.
3. 외부 대규모 언어 모델(LLM) API를 이용한 문장 초안 기능은 기술 검토 대상으로 둡니다.
4. 웹 기반 편집 화면과 외부 대규모 언어 모델 API를 결합하는 것으로 가정합니다.

## 시장 진입 가정

- 첫 대상: 전주 지역에서 온라인 소개 페이지가 필요한 소상공인
- 첫 제공 방식: 홈페이지 제작 교육과 템플릿 적용 지원을 묶은 워크숍
- 교육용 가격: 상점당 33만원
- 교육용 목표: 참여 상점 20곳, 유료 전환 30%, 매출 660만원
- 중장기 방향: 다른 지역 워크숍과 기관 협력으로 확대

## 추진 순서 가정

| 순서 | 할 일 | 기간·목표치 |
|---|---|---|
| 1 | 점주 질문 항목과 화면 흐름 설계 | 1~2개월차 |
| 2 | 최소기능제품과 템플릿 제작 | 3~5개월차, 서비스 1개와 템플릿 3개 |
| 3 | 사용성 확인과 개선 | 6개월차, 가상 참여 상점 10곳 |
| 4 | 유료 워크숍 방식 검증 | 7~8개월차, 참여 상점 20곳 |

## 예산과 자금

수업용 총사업비는 5천만원으로 가정합니다. 인건비 2천4백만원, 디자인·개발 외주비 1천만원, 서버·API 비용 6백만원, 홍보·교육 운영비 1천만원으로 구성합니다.

## 작성 금지

- `achievements.md`의 교육용 가상 활동을 실제 시장 검증이나 증빙 실적으로 표현하지 않기
- 정하지 않은 시간 절감률, 제작 시간, 고객 수, 만족도 만들지 않기
- 전국 확장, 기관 제휴, SaaS 전환을 확정 계획으로 만들지 않기
- 실제 개인정보, 학교명, 직장명, 생년월일을 추정하지 않기
