# 모두봄랩 교육용 가상 자료

이 폴더의 회사, 사람, 주소, 연락처, 실적과 이미지는 모두 수업을 위해 만든 가상 정보입니다. 실제 사업 신청이나 홍보에 사용하지 마세요.

## 저장 위치

- 이 폴더의 회사 문서와 이미지는 `naia-adk/data-company/workshop/`에 들어갑니다.
- 대표자 가상 개인정보 `profile.md`는 별도 `naia-adk/data-private/workshop/`에 들어갑니다.

학생용 ZIP은 이 구조를 미리 갖추고 있습니다. ZIP 전체를 `naia-adk`에 풀면 알맞은 위치에 들어가며 자동 입력 스크립트는 사용하지 않습니다.

실제 회사에 적용할 때는 이 가상 자료를 통째로 바꾸고, 숫자와 실적마다 증빙을 연결하세요. API 키와 Discord 토큰은 어떤 문서에도 넣지 않습니다.
