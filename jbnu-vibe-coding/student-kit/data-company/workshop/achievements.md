# 모두봄랩 — 교육용 가상 실적

> 아래 내용은 홈페이지와 제안서 구조를 실습하기 위해 만든 가상 기록입니다. 실제 증빙이 아니며 외부 제출에 사용할 수 없습니다.

| 시기 | 활동 | 교육용 가상 결과 | 근거 상태 |
|---|---|---|---|
| 2025년 4월 | 지역 소상공인 문제 인터뷰 | 가상 상점 5곳 인터뷰 | 교육용 설정, 실제 증빙 없음 |
| 2025년 5월 | 원페이지 시제품 제작 | 업종별 가상 시제품 3종 | 교육용 설정, 실제 증빙 없음 |
| 2025년 6월 | 사용성 의견 수집 | 가상 참여자 8명, 2회 | 교육용 설정, 실제 증빙 없음 |
| 2025년 7월 | 홈페이지 제작 워크숍 | 가상 2회, 가상 참여자 12명 | 교육용 설정, 실제 증빙 없음 |

## 표현 규칙

- 홈페이지에서는 `교육용 가상 사례`라고 명시합니다.
- 제안서에서도 수업을 위해 만든 가상 실적으로 사용합니다.

## 실제 회사 자료로 바꿀 때

표의 가상 활동과 결과를 본인 회사의 실제 활동과 결과로 바꿉니다.
