# NAIA 전북대 바이브 코딩 수업

## Discord와 Claude Code로 운영하는 원격 AI 작업실

깨끗한 Windows 노트북에서 `naia-adk`와 Claude Code를 준비하고, 가상 회사 홈페이지를 GitHub Pages에 배포한 뒤 Discord로 초기창업패키지 HWP 양식을 보내 HWPX 제안서를 돌려받는 실습입니다.

- 대상: 전북대학교·원광대학교 JST 공유대학 취·창업 동아리 참여자 25명
- 일시: 2026-07-28
- 진행 시간: 95분

## 바로 시작하기

1. [온라인 교재](https://wikidocs.net/book/20748)를 엽니다.
2. [학생용 실습자료 ZIP](jeonju-naia-student-kit.zip)을 내려받습니다.
3. 교재 1장에서 `naia-adk`를 받은 뒤, 교재 2장의 안내에 따라 ZIP 전체를 `naia-adk` 폴더에 풉니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `textbook/` | 위키독스에 게시하는 마크다운 교재와 화면 이미지 |
| `student-kit/` | 학생용 ZIP을 미리 풀어 확인할 수 있는 전체 실습자료 |
| `jeonju-naia-student-kit.zip` | 학생이 한 번에 내려받아 사용하는 실습자료 |

학생용 자료에는 다음이 포함됩니다.

- 교육용 가상 회사·대표자 정보와 PNG 이미지
- Discord 감시 스킬과 작업 프로그램
- 제안서 작성 스킬
- 2026년도 초기창업패키지 공식 HWP 사업계획서 양식

## 주의사항

- 샘플 회사와 인물은 모두 교육용 가상 정보입니다.
- API 키와 Discord 봇 토큰은 이 저장소에 입력하거나 올리지 마세요.
- 학교 API 설정은 교재대로 로컬 `.claude\settings.local.json`에 저장합니다.
- Discord 봇 설정은 로컬 `data-private\discord-claude\.env`에 저장합니다.
