# 부록 B. 복사해서 쓰는 요청문

## 좋은 요청문의 다섯 칸

1. 목적: 무엇을 왜 만드는가
2. 근거: 어떤 파일을 읽는가
3. 결과물: 파일 이름과 형식은 무엇인가
4. 제약: 무엇을 하지 말아야 하는가
5. 검증: 끝난 뒤 무엇을 확인하는가

## 홈페이지 제작

```text
../../data-company/workshop/company.md와 company-design.md만 읽어.
assets에 PNG 네 장은 이미 복사되어 있어.
index.html 한 파일만 Tailwind CSS CDN 원페이지로 작성해.
소개, 고객 문제, 해결 방법, 핵심 기능, 활동, 문의 섹션을 넣어.
SVG, 프레임워크, 설치, git 작업과 자료에 없는 수치·연락처 생성은 하지 마.
```

## 홈페이지 수정·자동 배포

```text
현재 홈페이지의 모바일 가독성만 개선해줘.
회사 사실은 바꾸지 말고 git diff와 이미지 경로를 확인해.
검증 후 commit하고 main에 push한 다음 gh로 Pages 상태와 공개 주소를 확인해줘.
```
