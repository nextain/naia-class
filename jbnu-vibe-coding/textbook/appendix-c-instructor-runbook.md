| 시간 | 단계 | 학생이 남길 결과 | 지연 시 전환 |
|---:|---|---|---|

## 강의 전 확인

- naia-adk 수업 기준 커밋 `a3f01f5`가 원격 `main`에 있는지 확인
- 깨끗한 Windows 11 사용자 계정에서 설치 명령 확인
- GitHub Pages용 강사 예비 저장소 준비
- 학생 자료 ZIP 다운로드와 압축 해제 확인
- 모든 샘플 파일에 교육용 가상 표시 확인
- PNG 로고·제품·활동 사진 네 장 확인
- 전북대학교 Claude 게이트웨이 1회 응답 확인
- 수업 Discord 초대 QR과 도우미 에이전트 응답 확인
- 개인 실습 서버 생성, 개인 봇 초대, Message Content Intent 확인
- HWP 첨부 다운로드, HWPX 생성과 재열기 확인
- 홈페이지와 제안서 요청을 각각 따로 실행해 결과 확인

## 진행 원칙

- API 키와 봇 토큰을 화면에 띄우지 않는다.
- 설치나 작업이 늦어지면 수업 채널의 도우미 에이전트에게 현재 단계와 오류를 질문하게 한다.
- Claude Code가 완료했다고 말한 것만으로 통과시키지 않는다. 파일, 로컬 화면, 공개 URL, Discord 첨부를 직접 확인한다.
- 홈페이지와 HWPX 미션을 한 요청에 섞지 않는다.
- 실습 중 실제 신청, 실제 고객 연락, 실제 개인정보 입력은 하지 않는다.
