# 6. Naia 소개 \[10분]

## 오늘 사용한 것과 앞으로의 모습

오늘은 안정적인 실습을 위해 공개 작업공간인 `naia-adk`와 Claude Code를 직접 연결했습니다. 이 구조에서 Claude Code가 파일을 읽고 작업하는 역할을 맡고, Discord 작업자가 외부 요청을 전달했습니다.

Naia는 이 경험을 더 쉽게 만드는 오픈소스 프로젝트입니다.

* `naia-agent`: Claude Code처럼 규칙과 자료를 읽고 실제 작업을 수행하는 에이전트
* `naia-shell`: 에이전트와 대화하고 상태를 확인하는 사용자 화면
* `naia-adk`: 에이전트가 사용할 규칙, 기술, 자료 구조를 담는 작업공간

원래는 이번 수업을 `naia-shell`에서 진행하려 했지만, 깨끗한 Windows 노트북에서 누구나 같은 시간 안에 설치하고 실습할 만큼 안정화하지 못했습니다. 그래서 오늘은 구조가 잘 보이고 검증된 Claude Code CLI를 사용했습니다. `naia-shell`과 `naia-agent`는 현재 안정화와 오픈소스 운영을 계속하고 있습니다.

## 오늘 경험한 핵심 개념

```text
사용자
  ├─ 로컬 Claude Code 대화 ── 홈페이지 제작·GitHub 배포
  └─ 개인 Discord 원격 요청 ── Windows 작업자 ── Claude Code ── HWPX 제안서
                                      │
                                      └─ naia-adk의 규칙·회사 자료·개인 자료·기술
```

핵심은 특정 모델 이름이 아닙니다. AI가 읽을 근거를 정리하고, 권한과 결과물 위치를 제한하고, 사람이 결과를 검증하는 작업 방식입니다.
