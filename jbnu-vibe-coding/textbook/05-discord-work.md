# 5. Discord로 일 시켜보기 \[20분]

## 목표

초기창업패키지 HWP 사업계획서 양식을 개인 Discord 서버에 첨부하고, 가상 회사 자료로 교육용 제안서를 작성하게 한 뒤 최종 `HWPX` 파일을 받습니다.

## 5-1. ZIP에 들어 있는 공식 양식 찾기

2장에서 학생용 ZIP을 `naia-adk`에 풀었다면 다음 파일이 들어 있습니다.

```text
naia-adk\workshop-files\2026년도 초기창업패키지 사업계획서 양식.hwp
```

이 파일은 [중소벤처기업부의 2026년도 초기창업패키지 공고](https://www.mss.go.kr/site/ulsan/ex/bbs/View.do?bcIdx=1065082\&cbIdx=254)에 첨부된 공식 양식입니다. 이 수업에서는 실제로 접수하지 않고 교육용 초안만 만듭니다.

## 5-2. Discord로 보내기

HWP 파일을 내 개인 실습 서버의 지정 채널에 첨부하고 다음 두 문장을 함께 보냅니다.

```text
첨부한 양식에 맞춰 제안서를 작성해줘.
완성본은 작업 폴더에 HWPX로 저장하고 이 채널에 첨부해서 보내줘.
```

이것으로 요청은 끝입니다. 작업자가 제안서 스킬, 가상 회사 자료, 저장 위치와 검증 절차를 Claude Code에 자동으로 전달합니다.

## 5-3. 결과 기다리기

Discord에는 요청 접수 메시지가 먼저 표시되고, 작업이 끝나면 다음 파일이 첨부됩니다.

* `초기창업패키지_모두봄랩_교육용.hwpx`
* `evidence.md`

문서를 읽고 HWPX로 만드는 동안 잠시 기다립니다. Discord 감시를 실행 중인 창은 닫지 않습니다.

## 5-4. 결과 파일 확인하기

Discord에서 HWPX를 내려받아 한글로 열어 봅니다.

* 파일 확장자가 `.hwpx`이고 한글에서 열리는가
* 원본 HWP 양식의 표와 큰 항목 순서를 따르는가
* 회사명, 제품, 대표자 내용이 가상 자료와 일치하는가

> 이 결과는 교육용 초안입니다. 실제 제출 전에는 사람이 내용과 증빙을 다시 확인해야 합니다.

> 화면 캡처 위치: Discord의 HWP 원본, 짧은 요청문, 최종 HWPX 다운로드 버튼과 한글에서 열린 결과 화면

## 작업자 종료

수업이 끝나면 작업자 PowerShell 창에서 `Ctrl+C`를 누릅니다. 노출이 의심되는 Discord 봇 토큰은 Developer Portal에서 재발급합니다.

## 완료 확인

* [ ] HWP 양식과 짧은 요청문을 Discord로 보냈다.
* [ ] 최종 `.hwpx` 파일을 받았다.
* [ ] 결과를 한글에서 직접 열어 보았다.
