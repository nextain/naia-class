# 부록 D. 쉬운 용어 사전

| 용어 | 쉬운 뜻 |
|---|---|
| CLI | 명령을 입력해 쓰는 프로그램 |
| PowerShell | Windows 명령 창 |
| Git | 파일 변경 기록과 복제 도구 |
| 저장소 | 코드·문서·이력을 둔 폴더 |
| naia-adk | 규칙·자료·스킬을 갖춘 AI 작업공간 |
| 모델 | 답을 만드는 AI 두뇌 |
| API | 프로그램끼리 요청하는 통로 |
| API 키 | API 권한을 증명하는 비밀 |
| 게이트웨이 | 여러 모델 앞의 공통 입구 |
| Claude Code | Claude에 파일 도구·규칙을 붙인 프로그램 |
| Discord 봇 | 메시지와 파일을 프로그램에 전달하는 계정 |
| 작업자 | Discord를 감시하고 Claude Code를 실행하는 프로그램 |
| 미션 | 한 번에 하나만 수행하는 독립 작업 |
| 세션 | 앞 대화와 작업 맥락을 잇는 단위 |
| inbox/outbox | 받은 원본/돌려줄 결과 폴더 |
| HWP/HWPX | 한글 문서 형식 |
| 스킬 | 작업 절차와 안전 규칙 |
| read-doc | 문서 텍스트 추출 스킬 |
| proposal-writing | 공식 양식과 근거를 확인해 제안서를 작성하고 HWPX로 검증하는 스킬 |
| Tailwind CSS | HTML class로 화면 모양을 정하는 도구 |
| CDN | 인터넷 주소에서 파일을 바로 불러오는 방식 |
| 환경변수 | 프로그램에 설정을 전달하는 이름표 |
| settings.local.json | Claude Code가 프로젝트를 시작할 때 자동으로 읽는 개인 설정 파일 |
| .env | Discord 작업기 설정을 줄 단위로 저장하는 `data-private`의 파일 |
| 상대경로 | 현재 파일 기준 위치 |
| Markdown | 간단한 문자 서식 문서 |
| 환각 | 근거 없이 사실처럼 만드는 오류 |
