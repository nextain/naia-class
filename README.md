# NAIA Class

NAIA를 활용한 강의와 실습에 필요한 공개 교육자료를 모아 둔 저장소입니다.

## 교육자료

| 과정 | 자료 |
|---|---|
| NAIA 전북대 바이브 코딩 수업 — Discord와 Claude Code로 운영하는 원격 AI 작업실 | [교재와 실습자료](jbnu-vibe-coding/) |

각 과정 폴더에는 온라인 교재, 학생용 ZIP, 압축을 푼 샘플 자료가 함께 들어 있습니다. API 키, Discord 봇 토큰과 실제 개인정보는 포함하지 않습니다.

## 저장소 운영 방향

앞으로 NAIA를 소개하거나 가르치는 콘텐츠와 수업자료는 이 저장소에 과정별 폴더로 정리합니다.

```text
naia-class/
└─ 과정명/
   ├─ README.md       과정 소개와 시작 방법
   ├─ textbook/       배포용 교재
   ├─ student-kit/    압축을 푼 실습자료
   └─ *.zip           학생용 일괄 다운로드
```

새 과정을 추가할 때는 처음 보는 학습자가 README만 보고 자료를 내려받고 시작할 수 있게 작성합니다.

## 이용 안내

교육자료의 안내문을 먼저 읽고 과정별 순서에 따라 사용하세요. 실습용 회사명·인명·연락처·주소·실적·이미지는 모두 교육용 가상 정보입니다.
